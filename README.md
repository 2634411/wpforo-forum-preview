# Предварительный макет форума

Публичный вариант оформления для согласования. Использована исходная иллюстрация с аркой и весами. Сохранены названия и ссылки разделов сайта.

Это статический макет: регистрация, вход и публикация сообщений не выполняются. Рабочая интеграция с WordPress/wpForo проверяется отдельно.
