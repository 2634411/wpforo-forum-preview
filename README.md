# Форум — демонстрация для согласования

13 исходных разделов, 30 редакционных тем, 60 ответов. Все разделы и темы открываются внутри демонстрации. Прямые ссылки используют фрагменты #/section/ и #/topic/, поэтому работают на GitHub Pages.

Вопросы и ответы подготовлены редакцией, не являются перепиской реальных участников. Вход и отправка сообщений доступны в WordPress, в демонстрации они не отправляют данные. Резервных копий, баз и доступов здесь нет.
